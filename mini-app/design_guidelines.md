# 尘间静（ZendMin） - 设计指南

## 1. 品牌定位

**应用定位**：帮助用户放松身心、改善睡眠、提升专注的冥想工具
**设计风格**：自然、平静、沉浸、治愈
**目标用户**：都市白领、睡眠困难者、焦虑人群、冥想初学者

## 2. 视觉风格

### 主题意象
- 主视觉：渐变星空/极光/自然风光
- 配色：宁静、自然、柔和
- 氛围：夜晚模式为主（冥想/睡眠场景）

### 配色方案（深色模式）

| 用途 | 变量名 | 颜色值 | Tailwind 类 |
|------|--------|--------|-------------|
| 背景 | `--background` | `#0a0a1a` (深邃夜空) | `bg-[#0a0a1a]` |
| 卡片背景 | `--card` | `#141428` (暗紫) | `bg-[#141428]` |
| 主色/强调 | `--primary` | `#7c6aef` (薰衣草紫) | `bg-[#7c6aef]` |
| 辅助色 | `--secondary` | `#2dd4bf` (薄荷绿) | `bg-[#2dd4bf]` |
| 成功色 | `--success` | `#4ade80` (翠绿) | `bg-[#4ade80]` |
| 警告色 | `--warning` | `#fbbf24` (暖黄) | `bg-[#fbbf24]` |
| 文案主色 | `--foreground` | `#f0f0f5` (柔白) | `text-[#f0f0f5]` |
| 次要文案 | `--muted-foreground` | `#9090a0` (灰紫) | `text-[#9090a0]` |
| 边框 | `--border` | `rgba(255,255,255,0.08)` | `border-white/10` |

### 渐变背景
```css
/* 极光渐变 - 用于首页背景 */
bg-gradient-to-b from-[#1a1a3e] via-[#141428] to-[#0a0a1a]

/* 紫色渐变 - 用于播放页 */
bg-gradient-to-br from-[#7c6aef]/20 via-transparent to-transparent
```

## 3. 组件使用规范

### 组件选型约束
通用 UI 组件必须优先使用 `@/components/ui/*`：

| 组件 | 适用场景 | 选型原则 |
|------|----------|----------|
| Button | 播放按钮、打卡按钮、行动按钮 | 主按钮用渐变紫色，辅助用描边 |
| Card | 课程卡片、白噪音卡片 | 圆角 16px，暗色背景，轻微发光 |
| Tabs | 课程分类切换 | 下划线样式，选中项高亮 |
| Progress | 播放进度、目标进度 | 细长条，渐变填充 |
| Slider | 定时器、音量控制 | 圆形滑块，渐变轨道 |
| Badge | 时长标签、状态标签 | 圆角胶囊，小尺寸 |
| Dialog | 确认弹窗、设置弹窗 | 暗色玻璃态背景 |
| Switch | 定时关闭开关、通知开关 | 紫色激活态 |
| Input | 搜索框 | 暗色背景，无边框 |

### 禁止手搓的通用组件
- ❌ 不要用 View/Text 手搓按钮
- ❌ 不要用 View/Text 手搓输入框
- ❌ 不要用 View/Text 手搓进度条
- ❌ 不要用 View/Text 手搓开关
- ❌ 不要用 View/Text 手搓卡片

## 4. 页面结构

### TabBar 导航（底部 4 个标签）

| 页面 | 图标 | 功能 |
|------|------|------|
| 首页 | Home / HomeIcon | 每日推荐、快速开始、统计数据 |
| 发现 | Compass / CompassIcon | 课程分类、冥想计划、全部课程 |
| 播放 | PlayCircle / PlayCircleIcon | 音频播放、播放列表 |
| 我的 | User / UserIcon | 打卡记录、设置、个人中心 |

### 页面路由

```
pages/index/index        - 首页
pages/discover/index     - 发现（课程库）
pages/player/index       - 播放器页
pages/profile/index      - 个人中心
pages/quiz/index         - 新手问卷
pages/stats/index        - 数据统计
```

## 5. 页面详细设计

### 5.1 首页 (pages/index)
- 顶部：问候语 + 日期 + 天气
- 今日推荐：根据问卷推荐课程
- 快速开始：白噪音入口
- 今日打卡：打卡卡片 + 连续天数
- 冥想时长：本周/本月统计

### 5.2 发现页 (pages/discover)
- 顶部：搜索框
- 分类 Tabs：全部 / 入门 / 睡眠 / 减压 / 专注
- 课程列表：卡片流
- 冥想计划入口：7天/14天/30天计划

### 5.3 播放器页 (pages/player)
- 顶部：关闭按钮
- 中央：音频封面 + 动态光效
- 音频信息：标题 + 引导文案
- 进度条：可拖动
- 控制栏：上一首 / 播放暂停 / 下一首
- 辅助功能：定时、循环、白噪音叠加

### 5.4 个人中心 (pages/profile)
- 用户信息卡片
- 打卡日历（本月）
- 统计数据（总时长、连续天数、完成课程）
- 设置入口

## 6. 间距系统

| 场景 | 值 | Tailwind |
|------|-----|----------|
| 页面水平边距 | 16px | `px-4` |
| 卡片内边距 | 16px | `p-4` |
| 卡片间距 | 12px | `gap-3` |
| 组件间距 | 8px | `gap-2` |
| 大区块间距 | 24px | `mb-6` |

## 7. 圆角系统

| 元素 | 圆角 | Tailwind |
|------|------|----------|
| 页面容器 | 0 | - |
| 卡片 | 16px | `rounded-2xl` |
| 按钮 | 12px | `rounded-xl` |
| 头像 | 50% | `rounded-full` |
| 小标签 | 9999px | `rounded-full` |
| 输入框 | 12px | `rounded-xl` |

## 8. 图标规范

使用 lucide-react-taro 图标库，尺寸规范：
- TabBar 图标：24px
- 功能图标：20px
- 装饰图标：16px

## 9. 小程序特殊约束

- 包体积：静态资源必须上传 TOS
- TabBar 图标：仅支持本地 PNG，放在 `src/assets/tabbar/`
- 音频：使用网络 URL 引用
- 首屏加载：骨架屏优化

## 10. 状态设计

### 加载态
- 使用 Skeleton 组件
- 圆角与目标卡片一致

### 空状态
- 插画 + 文案
- 引导行动按钮

### 错误态
- 友好提示
- 重试按钮
